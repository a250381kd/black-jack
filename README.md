# black-jack

Proyecto de blackjack con estética inspirada en Balatro, construido en JavaScript vanilla con Vite.

## Cómo arrancar

```bash
npm install
npm run dev -- --host
```

## Objetivo

Consigue 21 puntos o acercarte lo máximo posible sin pasarte.

## Características

- Baraja aleatoria
- Lógica de blackjack
- Interfaz tipo casino con estilo neón
- Pantalla de carga inicial
- Modo simple para empezar

## Estructura

- `src/models`: lógica del juego
- `src/main.js`: render y control de la interfaz
- `src/style.css`: visual del proyecto

## Siguientes pasos recomendados

- Añadir apuestas por ronda
- Introducir animaciones de reparto
- Añadir efectos sonoros y UI de victoria/derrota

## Recomendaciones para el proyecto

- Mantener la lógica separada del render
- Usar clases para cada entidad del juego
- Revisar la progresión del dinero para equilibrar la dificultad
- Mejorar el flujo visual con animaciones suaves y microinteracciones
