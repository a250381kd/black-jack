# black-jack

Mini proyecto de blackjack con un estilo visual inspirado en Balatro.

## Cómo arrancarlo

```bash
npm install
npm run dev -- --host
```

Luego abre la URL que te indique Vite en tu navegador.

## Controles

- Nueva ronda: empieza una partida nueva
- Pedir carta: toma una carta adicional
- Plantarse: termina tu turno y deja que el crupier juegue

## Objetivo

Consigue una mano lo más cercana posible a 21 sin pasarte.
